# Security reports

Use GitHub's private vulnerability reporting when enabled. Otherwise contact the
maintainer through the contact information on their GitHub profile before posting
exploit details publicly. Include the affected commit, reproduction and impact.

The receiver accepts unauthenticated UDP image packets. Use it on a controlled
network and bind only the required interface. Npcap/tshark and FTDI drivers are
optional system components; install them separately from their publishers.

No clinical validation or suitability for medical decisions is claimed.
